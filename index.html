New to behaviours based interviewing?

Aim for 6–10 questions in a one hour interview. Spread them across a few different behaviours and values rather than going deep on one, and use the same set for every candidate for the same role so you can compare fairly.

Some questions have probes attached, shown in an amber box marked Probes if needed. These are follow-ups you only ask if part of the answer is missing. They come with the question and don’t count as extra questions.

Interview Record

Listen for a full STAR answer

  • Situation: where were they and what was going on?
  • Task: what did they need to do, and why was it on them?
  • Action: what did they actually do? Listen for “I”, not “we”.
  • Result: what happened, and what did they learn?

The amber “Probes if needed” boxes are follow-ups, not questions in their own right. Only use them if part of the answer is missing. Give the candidate time to think; silence is fine.
